# Security Policy

This repository maintains `pi-permissions`, `pi-profile`, `pi-subagent`, and `pi-todo`. Security issues in these extensions and their repository tooling are in scope. Report issues in the Pi runtime to its upstream maintainers.

Extensions execute with the permissions of the Pi process. The permission extension is an application-level gate, not an operating-system sandbox.

## Reporting

Report vulnerabilities privately through this repository’s GitHub Security Advisories. Include the affected extension and version, configuration, reproduction steps, and demonstrated impact. Do not post credentials or security-sensitive details in public issues.
